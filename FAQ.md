# FAQ и Примеры

## Часто задаваемые вопросы

### Q: Нужен ли API ключ Google?

**A:** Нет! Приложение использует публичный API Google Visualization, который не требует API ключей. Достаточно сделать таблицу публично доступной.

---

### Q: Можно ли использовать с приватными таблицами?

**A:** В текущей версии - нет. Таблица должна быть доступна по ссылке. Для работы с приватными таблицами потребуется добавить OAuth авторизацию (планируется в версии 2.2).

---

### Q: Как часто обновляются данные?

**A:** Данные загружаются при:
1. Открытии страницы
2. Обновлении страницы (F5)
3. Сохранении новых настроек

В будущих версиях планируется автоматическое обновление.

---

### Q: Сколько данных может обработать приложение?

**A:** Оптимизация позволяет комфортно работать с:
- ✅ До 5000 строк в таблице "Матрица"
- ✅ До 500 подразделений в "Легенде"
- ✅ До 20 столбцов с ролями

Для больших объемов рекомендуется использовать фильтры.

---

### Q: Можно ли изменить набор ролей?

**A:** Да! Отредактируйте объект `ROLE_INFO` в файле `app.js`:

```javascript
const ROLE_INFO = {
  'О': 'Описание роли О',
  'Н': 'Новая роль',  // Добавьте вашу роль
  // ...
};
```

---

### Q: Как добавить новый столбец для фильтрации?

**A:** Отредактируйте `FILTER_CONFIG` в `app.js`:

```javascript
const FILTER_CONFIG = [
  { id: 'filter-function', label: 'Функция', field: 'func' },
  { id: 'filter-новое', label: 'Новое поле', field: 'newField' },
  // ...
];
```

И добавьте соответствующий HTML элемент в `index.html`.

---

### Q: Данные не загружаются, что делать?

**A:** Проверьте по шагам:

1. **Проверьте доступ:**
   ```
   https://docs.google.com/spreadsheets/d/ВАШ_ID/edit
   ```
   Откройте в режиме инкогнито - должно открыться

2. **Проверьте ID таблицы:**
   - ID не должен содержать `/edit` или другие части URL
   - Только сам ID: `1ABC...xyz`

3. **Проверьте названия листов:**
   - Точно совпадают с вашими листами?
   - Регистр важен: "Матрица" ≠ "матрица"

4. **Откройте консоль браузера:**
   ```
   F12 → Console
   ```
   Посмотрите подробное сообщение об ошибке

---

### Q: Можно ли экспортировать в PDF?

**A:** Сейчас только Excel. Экспорт в PDF планируется в версии 2.2.

Временное решение:
1. Экспортируйте в Excel
2. Откройте в Excel/Google Sheets
3. Сохраните как PDF

---

### Q: Как работает иерархия подразделений?

**A:** Система использует код типа `1.5.1`:
- `1` = Департамент (первый уровень)
- `1.5` = Отдел (второй уровень)
- `1.5.1` = Должность (третий уровень)

Соответствия берутся из листа "Легенда с уровнями".

---

### Q: Что делать, если ячейка содержит несколько должностей?

**A:** Приложение автоматически парсит такие ячейки!

**Формат:**
```
1.5.1 / Главный архитектор 1.6.3 / Начальник отдела 1.7.2 / Инженер
```

Каждая пара "код / должность" создает отдельную строку в таблице.

---

### Q: Можно ли изменить цветовую схему?

**A:** Да! Отредактируйте переменные в `style.css`:

```css
:root {
  --purple: #6b4eff;      /* Ваш цвет */
  --purple-soft: #f4f1ff;
  --border: #e6e0fa;
  --muted: #666;
}
```

## Примеры использования

### Пример 1: Базовая структура

**Лист "Легенда с уровнями":**
```
Номер | Наименование
1     | Департамент девелопмента
1.1   | ДДУ
1.1.1 | Начальник отдела ДДУ
1.2   | ПО
1.2.1 | Главный архитектор
2     | Департамент строительства
2.1   | ОСК
```

**Лист "Матрица":**
```
№ | Блок | Функция | Продукт | О | И
1 | ... | Проектирование | План | 1.2.1 / Главный архитектор | 1.1.1 / Начальник отдела ДДУ
```

**Результат:**
- Функция: Проектирование
- Департамент (О): Департамент девелопмента
- Отдел (О): ПО
- Должность (О): Главный архитектор
- Роль (О): О

---

### Пример 2: Несколько ответственных

**Ячейка роли "О":**
```
1.2.1 / Главный архитектор 2.1.5 / Главный инженер
```

**Результат:** Создастся 2 строки:
1. Главный архитектор (Департамент девелопмента / ПО)
2. Главный инженер (Департамент строительства / ОСК)

---

### Пример 3: Комплексный фильтр

**Задача:** Найти все функции, где:
- Ответственный из "Департамента девелопмента"
- Исполнитель - "Инженер"
- Функция связана с "Проектированием"

**Действия:**
1. Фильтр "Департамент" → выбрать "Департамент девелопмента"
2. Фильтр "Роль" → выбрать "О" (ответственный)
3. Фильтр "Функция" → выбрать функции с "Проект"

Затем отдельно:
1. Фильтр "Должность" → выбрать "Инженер"
2. Фильтр "Роль" → выбрать "И" (исполнитель)

---

### Пример 4: Экспорт для презентации

**Задача:** Подготовить отчет для руководства

**Действия:**
1. Выбрать нужные функции через фильтры
2. Отсортировать по департаментам
3. Нажать "Экспорт"
4. Открыть Excel файл
5. Добавить графики/диаграммы
6. Сохранить как PDF для презентации

## Кейсы использования

### Кейс 1: Адаптация нового сотрудника

**Проблема:** Новый сотрудник не понимает, кто за что отвечает

**Решение:**
1. Фильтр "Отдел" → выбрать отдел сотрудника
2. Показать все функции отдела
3. Навести на роли для подробного описания

---

### Кейс 2: Оптимизация процессов

**Проблема:** Нужно найти функции, где один человек - и ответственный, и исполнитель

**Решение:**
1. Экспортировать полную таблицу
2. В Excel отфильтровать строки где О = И
3. Проанализировать нагрузку

---

### Кейс 3: Планирование найма

**Проблема:** Определить, каких специалистов не хватает

**Решение:**
1. Фильтр "Роль" → выбрать "О" (ответственные)
2. Посмотреть распределение по отделам
3. Найти отделы с перегрузкой
4. Экспортировать для HR отдела

---

### Кейс 4: Аудит функций

**Проблема:** Проверить, что у всех функций есть ответственные

**Решение:**
1. Экспортировать полную таблицу
2. В Excel найти функции без роли "О"
3. Доработать матрицу в Google Sheets
4. Обновить страницу
