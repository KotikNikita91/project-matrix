## 📚 Как использовать

### Быстрый старт (5 минут):

1. **Распакуйте архив**
2. **Сделайте таблицу публичной:**
   - Настройки доступа → "Все, у кого есть ссылка"
3. **Скопируйте ID таблицы** из URL
4. **Запустите локально:**
   ```bash
   python -m http.server 8000
   ```
5. **Откройте:** http://localhost:8000
6. **Введите ID таблицы** в модальном окне
7. **Готово!**

### Развертывание в продакшн:

**GitHub Pages (рекомендуется):**
```bash
git init
git add .
git commit -m "Init"
git push
# Settings → Pages → Deploy from main
```

**Netlify (еще проще):**
- Перетащите папку на netlify.com
- Готово!
