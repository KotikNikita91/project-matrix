# 🚀 Быстрый старт

## За 5 минут запустите вашу функциональную матрицу!

### Шаг 1: Подготовка Google Sheets (2 минуты)

1. **Откройте вашу таблицу**
2. **Сделайте публичной:**
   - Нажмите "Настройки доступа" (правый верхний угол)
   - Выберите "Все, у кого есть ссылка"
   - Права: "Читатель"
   - Сохраните

3. **Скопируйте ID таблицы:**
   ```
   https://docs.google.com/spreadsheets/d/1AbC2dEf3GhI4jKl5MnO/edit
                                            ^^^^^^^^^^^^^^^^^^^^
                                            Вот это ID
   ```

### Шаг 2: Запуск приложения (1 минута)

**Вариант A: Локально (для тестирования)**
```bash
# Распакуйте архив
# Перейдите в папку
cd functional-matrix

# Запустите локальный сервер (любой из вариантов):
python -m http.server 8000
# или
npx http-server
# или
php -S localhost:8000

# Откройте браузер
http://localhost:8000
```

**Вариант B: GitHub Pages (для продакшена)**
```bash
# Загрузите на GitHub
git init
git add .
git commit -m "Init"
git push

# Активируйте GitHub Pages в Settings → Pages
# Готово! Ссылка: https://username.github.io/repo/
```

### Шаг 3: Настройка (1 минута)

1. Откроется модальное окно
2. Вставьте ID таблицы
3. Проверьте названия листов:
   - Матрица
   - Легенда с уровнями
4. Нажмите "Сохранить и загрузить"

### Шаг 4: Готово! ✅

Теперь вы можете:
- ✅ Фильтровать данные
- ✅ Сортировать строки
- ✅ Экспортировать в Excel
- ✅ Видеть подсказки по ролям

## Структура данных

### Минимально необходимые листы:

#### Лист "Матрица"
```
| A (№) | B (Блок) | C (Функция) | D (Продукт) | E (О) | F (И) | ... |
|-------|----------|-------------|-------------|-------|-------|-----|
| 1     | ...      | Проектир.   | План        | 1.1.1/Архитектор | ... |
```

#### Лист "Легенда с уровнями"
```
| A (Номер) | B (Наименование) |
|-----------|------------------|
| 1         | Департамент      |
| 1.1       | Отдел            |
| 1.1.1     | Должность        |
```

## Проверка работоспособности

### ✅ Контрольный список:

- [ ] Таблица публична (открывается в режиме инкогнито)
- [ ] ID скопирован правильно (без /edit и других частей)
- [ ] Листы называются точно: "Матрица" и "Легенда с уровнями"
- [ ] В ячейках ролей формат: "код / должность"
- [ ] Локальный сервер запущен (или сайт задеплоен)

### 🐛 Если что-то не работает:

1. **F12 → Console** - смотрим ошибки
2. **Проверяем доступ** к таблице
3. **Читаем FAQ.md** - там ответы на 90% вопросов

## Кастомизация (опционально)

### Изменить цвета
Откройте `style.css`, найдите:
```css
:root {
  --purple: #6b4eff;  /* Ваш цвет */
}
```

### Добавить роли
Откройте `app.js`, найдите:
```javascript
const ROLE_INFO = {
  'НОВАЯ': 'Описание новой роли',
};
```

### Изменить фильтры
Откройте `app.js`, найдите:
```javascript
const FILTER_CONFIG = [
  // Добавьте новый фильтр
];
```
