# Функциональная матрица v2.1

Веб-приложение для визуализации функциональной матрицы с данными из Google Sheets.

## ✨ Новое в версии 2.1

- ✅ **Роли в столбцах** - правильная структура таблицы
- ✅ **Краткие названия** - автоматическая подстановка сокращений из легенды
- ✅ **Модальное окно легенды** - расшифровка всех сокращений
- ✅ **Экспорт в PDF** - сохранение в PDF формате
- ✅ **Тултипы на ролях** - подсказки при наведении на заголовки
- ✅ **Скрытые настройки** - кнопка настроек скрыта от пользователей

## 📊 Структура данных

### Лист "Легенда с уровнями" (3 колонки!)

| A (Номер) | B (Сокращение) | C (Полное наименование) |
|-----------|----------------|-------------------------|
| 1         | ДД             | Департамент девелопмента|
| 1.1       | ДДУ            | Управление проектами    |
| 7         | HR             | HR департамент          |
| 7.1       | HR BP          | HR Business Partner     |

### Лист "Матрица"

| №   | Блок | Функция   | Продукт | О         | И             | К |
|-----|------|-----------|---------|-----------|---------------|---|
| 32.1| ...  | Проектир. | План    | 7 / HR BP | 7.1 / Менеджер|...|

**Результат → "HR / HR BP"** (код 7 → сокращение HR из легенды)

## 🚀 Быстрый старт (5 минут)

### 1. Подготовьте таблицу

1. Создайте Google Sheets с 2 листами: "Матрица" и "Легенда с уровнями"
2. Сделайте публичной: "Настройки доступа" → "Все, у кого есть ссылка"
3. Скопируйте ID из URL

### 2. Настройте app.js

Откройте `app.js`, строка 8:
```javascript
const DEFAULT_SHEET_ID = 'ВАШ_ID_ЗДЕСЬ';
```

### 3. Разместите

**GitHub Pages / Netlify** - готово!

### 4. Готово!

Пользователи открывают ссылку → сразу видят данные.
