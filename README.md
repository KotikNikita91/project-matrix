# Функциональная матрица с Google Sheets

Веб-приложение для визуализации функциональной матрицы с данными из Google Sheets.

## Возможности

✅ **Загрузка из Google Sheets** - работа с живыми данными без необходимости экспорта
✅ **Иерархическая структура** - автоматическое разрешение департаментов и отделов по кодам
✅ **Мощные фильтры** - по функциям, департаментам, отделам, должностям и ролям
✅ **Сортировка** - по любому столбцу
✅ **Экспорт в Excel** - сохранение отфильтрованных данных
✅ **Тултипы** - подсказки с описанием ролей
✅ **Сохранение состояния** - фильтры сохраняются между сессиями

## Структура данных

### Лист "Матрица"

Должен содержать следующие столбцы:

| Столбец | Название | Описание |
|---------|----------|----------|
| A | № п/п | Порядковый номер функции |
| B | Блок функций | Иерархия функций |
| C | Функция/операция | Название функции |
| D | Продукт функции | Результат функции |
| E-M | Роли | Столбцы с ролями (О, И, В, и т.д.) |

**Формат ячеек с ролями:**
```
1.5.1 / Главный архитектор 1.6.3 / Начальник отдела
```

Где:
- `1.5.1` - код подразделения/должности из легенды
- `/` - разделитель
- `Главный архитектор` - название должности

### Лист "Легенда с уровнями"

Справочник иерархии подразделений:

| Столбец | Название | Пример |
|---------|----------|--------|
| A | Номер | 1, 1.1, 1.1.1 |
| B | Наименование | Департамент, Отдел, Должность |

**Пример:**
```
1       → Департамент девелопмента
1.1     → ДДУ (Отдел)
1.1.1   → Начальник отдела (Должность)
```

## Настройка Google Sheets

### 1. Подготовьте таблицу

1. Создайте таблицу Google Sheets
2. Создайте лист "Матрица" с данными
3. Создайте лист "Легенда с уровнями" со справочником

### 2. Настройте доступ

**ВАЖНО:** Таблица должна быть доступна по ссылке!

1. Откройте таблицу в Google Sheets
2. Нажмите кнопку "Настройки доступа" (правый верхний угол)
3. Выберите "Все, у кого есть ссылка"
4. Установите права "Читатель"
5. Сохраните

### 3. Найдите ID таблицы

ID таблицы находится в URL:
```
https://docs.google.com/spreadsheets/d/[ID_ТАБЛИЦЫ]/edit
                                         ^^^^^^^^^^^^^^
```

Пример: `1AbC2dEf3GhI4jKl5MnO6pQr7StU8vWx9YzA`

### 4. Запустите приложение

1. Откройте `index.html` в браузере
2. При первом запуске откроется модальное окно настроек
3. Введите ID таблицы
4. Укажите названия листов (по умолчанию уже заполнены)
5. Нажмите "Сохранить и загрузить"

Настройки сохраняются в LocalStorage браузера.

## Использование

### Фильтрация

Кликните на любой выпадающий список в шапке:
- **Функция** - фильтр по названиям функций
- **Департамент** - фильтр по департаментам (первый уровень иерархии)
- **Отдел** - фильтр по отделам (второй уровень)
- **Должность** - фильтр по должностям
- **Роль** - фильтр по типам ролей (О, И, В, и т.д.)

Можно выбрать несколько значений. Фильтры работают совместно (логика AND).

### Сортировка

Кликните на заголовок любого столбца для сортировки.
Повторный клик меняет направление (↑↓).

### Экспорт

Кнопка "Экспорт" сохраняет текущий отфильтрованный набор данных в Excel файл с форматированием.

### Сброс фильтров

Кнопка "Сбросить" очищает все фильтры и возвращает к полному набору данных.

## Роли

| Код | Название | Описание |
|-----|----------|----------|
| О | Ответственный | Организует и координирует выполнение функции |
| В/ВО | Выполняющий | Непосредственно выполняет работу |
| У | Утверждающий | Принимает и утверждает результат |
| К | Консультант | Даёт экспертные рекомендации |
| И | Информируемый | Получает информацию о ходе или результате |
| П | Помощник | Содействует выполнению функции |
| ПК | Помощник-консультант | Сочетает помощь и экспертизу |

При наведении на роль в таблице появляется подсказка с полным описанием.

## Технические детали

### Зависимости

- **SheetJS (XLSX)** - экспорт в Excel
- Vanilla JavaScript - нет фреймворков
- LocalStorage - сохранение настроек и фильтров

### Браузеры

Работает во всех современных браузерах:
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+

### API Google Sheets

Приложение использует публичный API Google Visualization для получения данных:
```
https://docs.google.com/spreadsheets/d/[ID]/gviz/tq?tqx=out:json&sheet=[НАЗВАНИЕ]
```

**Преимущества:**
- ✅ Не требует API ключей
- ✅ Работает с публичными таблицами
- ✅ Быстрая загрузка

**Ограничения:**
- ❌ Требует публичный доступ к таблице
- ❌ Нет поддержки приватных таблиц без дополнительной авторизации

Отредактируйте объект `ROLE_INFO` в `app.js`:
```javascript
const ROLE_INFO = {
  'НовыйКод': 'Описание новой роли',
  // ...
};
```

Отредактируйте `FILTER_CONFIG` в `app.js`:
```javascript
const FILTER_CONFIG = [
  { id: 'filter-function', label: 'Функция', field: 'func' },
  // Добавьте новые фильтры здесь
];
```

## Устранение неполадок

### Данные не загружаются

1. **Проверьте доступ к таблице:**
   - Откройте таблицу в режиме инкогнито
   - Если не открывается - настройте публичный доступ

2. **Проверьте названия листов:**
   - Откройте настройки (⚙️)
   - Убедитесь, что названия точно совпадают

3. **Проверьте консоль браузера:**
   - F12 → Console
   - Посмотрите на ошибки

### Фильтры не работают

1. Проверьте, что в ячейках нет лишних пробелов
2. Убедитесь, что формат данных соответствует описанному
3. Попробуйте "Сбросить" фильтры

### Экспорт не работает

1. Убедитесь, что есть данные для экспорта
2. Проверьте, что браузер разрешает скачивание файлов
3. Попробуйте другой браузер
